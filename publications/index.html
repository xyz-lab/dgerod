Patents

Inventor in ten patent families assigned to OMRON Corporation, six of them granted. They come from four lines of work on robot controllers; the numbers link to Google Patents.

Computing resources for robot control (2022)

  • Technology that flexibly responds to changes in computational resources required to realize robot motions. Granted: JP7771792B2 (2025).
  • Control system capable of optimally arranging modules required for controlling one or more robots. Application: WO2023145362A1 (2023).
  • Auxiliary computing resource for robot control. Application: WO2023145361A1 (2023).

Two-level distributed robot controller (2020)

  • Distributed control system for robots. Granted: US12275151B2, EP4119306B1, CN115151874B (2025), JP7452124B2 (2024).
  • Multi-robot controller for multiple and different types of robots. Granted: US11855907B2, JP7327225B2 (2023).
  • Robot setting information shared between controllers. Granted: JP7592975B2 (2024).
  • Load distribution between controllers via local trajectory generation. Application: WO2021181800A1 (2021).

Motion constraints for SCARA robots (2017)

  • Preventing damage to a cable during an operation under control of a SCARA robot. Granted: US10625418B2 (2020), EP3369533B1, JP6859756B2, CN108527375B (2021).
  • Optimized workspace definition of SCARA robot to avoid forbidden zones. Granted: US10625417B2 (2020), JP6859757B2, CN108527359B (2021).

Conveyor tracking (2014)

  • Apply offset to move a robot when doing conveyor tracking. Application: EP2902862A1 (2015).
